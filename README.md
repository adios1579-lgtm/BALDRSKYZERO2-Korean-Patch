# BALDR SKY ZERO 2 한글패치

**[최신 패치 다운로드](https://github.com/adios1579-lgtm/BALDRSKYZERO2-Korean-Patch/releases/latest)**

2026-10-10 최신 누적 한글화와 **공식 업데이트 1.0.4, 한글 오프닝**, 자동·수동 업데이트를 포함합니다. 원본 Windows 게임이 별도로 필요합니다.

## 설치

1. Releases에서 `BSZ2_KO_PATCH_20261010.zip`를 받습니다. `Source code`는 패치가 아닙니다.
2. 게임을 종료하고 ZIP을 게임 폴더 밖에 모두 압축 해제합니다.
3. `BSZ2_KO_SETUP.exe`를 열고 `bsz2.exe`가 있는 게임 폴더를 선택합니다.
4. 설치기가 필요한 공식 업데이트와 한글패치를 한 번에 적용합니다.
5. 설치 후 게임 폴더의 `BSZ2_KO.exe`로 실행합니다.

공식 초기판부터 지원하며 이미 공식 최신 버전이면 그 단계를 자동으로 건너뜁니다. 별도 공식 업데이터 실행은 필요하지 않습니다. 다른 구버전 한글패치/개별 수정 파일은 설치 전에 차단합니다. 기존 세이브와 설정은 보존됩니다.

## 자동 업데이트

- 게임 실행 시 최신 버전과 변경 내용을 확인하고 동의한 경우에만 적용합니다.
- 인터넷 없음·조회 실패 시 정상 설치된 현재 게임을 실행합니다.
- `BSZ2_KO_UPDATE.exe`는 업데이트만 수행하고 게임을 실행하지 않습니다.
- 세이브·개인 설정은 업데이트 대상에서 제외됩니다. 중단된 교체는 다음 실행에 복구합니다.
- 업데이트에는 GitHub 계정이나 토큰이 필요하지 않습니다.

## 포함 내용과 검증

본문·서술 UI 60,589행, UI 742행, 이름표 145개 검수, UI31, 최신 공통 루트408행 및 한글 오프닝을 포함합니다.

파일 해시, 압축 내부 전 항목, 설치·재설치·오류 복원·세이브 보존 및 누적 업데이트를 검사했습니다. **최신 누적본의 실제 화면·입력·음성·저장/불러오기 전수 QA는 아직 완료되지 않았습니다.** 원본 전체 게임과 개인 데이터는 포함하지 않습니다.
